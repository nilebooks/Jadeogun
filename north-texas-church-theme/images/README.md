# Images Directory

This directory contains theme images and assets.

## Required Images

### Logo
- **File**: `logo.png`
- **Recommended Size**: 300x100px
- **Format**: PNG with transparent background
- **Usage**: Site header and footer

### Pastor/Team Photos
- **File**: `pastor1.jpg` (and additional as needed)
- **Recommended Size**: 400x400px
- **Format**: JPG
- **Usage**: About section and team member fallback

## Image Optimization

Before uploading images:
1. Optimize file size (use TinyPNG or similar)
2. Use appropriate dimensions
3. Use WebP format when possible
4. Add descriptive alt text

## Image Locations

- **Header Logo**: Can also be set via Appearance > Customize > Site Identity
- **Featured Images**: Upload via WordPress Media Library
- **Theme Images**: Place in this directory

## Best Practices

- Keep images under 500KB when possible
- Use 2x resolution for retina displays
- Maintain aspect ratios
- Compress before upload
- Use descriptive filenames
